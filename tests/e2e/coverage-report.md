## How to read this report

Each row is one closed issue. The **Status** column is one of:

- **fully covered** - a spec (or specs) asserts the behaviour the issue describes, with a named test that proves it.
- **partial coverage** - a spec touches the surface but does not assert the full intent, or asserts only a smoke-level check. The **Routes to** column names which downstream ticket (#66, #67, #68) is best placed to address it.
- **no coverage (gap)** - no spec in the suite exercises this issue. The **Routes to** column names which downstream ticket should own it.
- **research / non-feature (excluded)** - the issue is a research output, design doc, or meta-ticket, not an implemented feature. Excluded from the test-coverage target per the map destination.

Static analysis only - the suite was not run. Pass/fail and runtime triage are in section 3.
